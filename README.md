# Holiday Package Purchase Prediction

Predicting customer purchase behavior using Machine Learning to help travel companies improve marketing efficiency and customer targeting.

---

## Problem Statement

Travel companies spend significant resources promoting holiday packages to a large customer base. However, not every customer is equally likely to purchase a travel package.

The objective of this project is to build a machine learning classification model that predicts whether a customer will purchase a holiday package based on demographic, behavioral, and travel-related information.

Such predictions enable businesses to:

- Improve marketing campaign effectiveness
- Reduce customer acquisition cost
- Increase conversion rates
- Prioritize high-potential customers

---

## Dataset

The dataset contains customer demographic, financial, and travel-related information.

Typical features include:

- Age
- Annual Income
- Occupation
- Number of Trips
- Passport Status
- Family Size
- Preferred Property Type
- Marital Status
- Designation
- Monthly Income
- Product Preference

Target Variable

- Purchase (Yes / No)
